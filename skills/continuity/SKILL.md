# continuity：接着上次干

你每轮结束会自动留下一条断点（做了什么/下一步/还差什么），新会话开头会自动看到最近五条。
不用特意提醒自己要「记住上下文」，它自己会续上。

## 什么时候该主动用

- **要断开了、或者任务很长**：`continuity_breakpoint` 手动记一条，把下一步写清楚
  「接着改 auth 的 token 刷新 → 补重试 → 还没跑测试」比「在做项目」有用得多。
- **接手别人做过的事**：先 `continuity_breakpoints` 看最近几条，别从头猜。
- **怀疑自己被改了**：`continuity_attest({})` 核对上次存过的文件指纹。
  会明确告诉你哪些文件变了、哪些没变。不要靠「感觉」判断。
- **想知道谁动过什么**：`continuity_ledger`。

记得的事项：

- 断点里写**具体动作**，不要写「继续工作」这种空话。
- `continuity_attest` 第一次要传 `paths`（把要盯的文件列进去），之后不传就是核对。
- 数据在 `<工作区>/.dsh-continuity/`，纯 JSONL，能直接看。
